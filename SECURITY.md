# Security

Found a vulnerability? Use
[private vulnerability reporting](https://github.com/Paulus1337/OpenPhoenix/security/advisories/new).
No public issues for exploitable bugs, please.

The security model (path jail, command gate, secret redaction, fail-closed
allowlists, output clipping) is documented in
[wiki/Security](https://github.com/Paulus1337/OpenPhoenix/wiki/Security).

Supported: latest release only.
