# Reporting Issues

Found a bug? Use
[private reporting](https://github.com/Paulus1337/OpenPhoenix/security/advisories/new).
No public issues for harmful bugs, please.

The protection model (path jail, command gate, secret redaction,
fail-closed allowlists, output clipping) is documented in
[wiki/Security](https://github.com/Paulus1337/OpenPhoenix/wiki/Security).

Supported: latest release only.
